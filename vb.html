Chapter 1

Introduction to Visual Basic

This chapter covers object-oriented terminology and concepts, the basic files comprising a VB project, the Visual Studio IDE, and the first hands-on project introducing objects, properties, and methods.

1 What VB.Net Is

VB.Net is a programming language inside Microsoft Visual Studio. It is object-oriented (you work with objects) and event-driven (code responds to user actions). You build Windows Forms Applications that run on the .NET Framework.

How code runs

  • You write human-readable code in VB
  • Code compiles to MSIL (Microsoft Intermediate Language)
  • MSIL runs inside the CLR (Common Language Runtime) — a component of the .NET Framework
  • Visual Studio includes several languages: VB, C#, C++, F#, ASP.NET — all compile to the same MSIL

Editions of VB

  • Express Edition — free, downloadable
  • Professional, Premium, Ultimate — used in industry
  • VB 10 is the current version. VB 6 and earlier are NOT .NET-compatible

Chapter 1 Code

Your First Program

The smallest working VB.Net program: a form with buttons that display information to read-only textboxes, a Reset button, a Print button, and an Exit button.

1 The Event Sub Procedure

Double-clicking a control in the Designer generates a sub procedure for its default event:

Private Sub Display1Button_Click(ByVal sender As System.Object, _
                                ByVal e As System.EventArgs) _
                                Handles Display1Button.Click
    ' Your code goes here
End Sub

Breaking down the signature

  • Private — scope keyword
  • Sub — this is a sub procedure (no return value)
  • Display1Button_Click — VB auto-generates: controlname_eventname
  • (ByVal sender As Object, ByVal e As EventArgs) — two parameters (ignore for now)
  • Handles Display1Button.Click — tells VB "run this when this button is clicked"

2 The Remark Statement

Remarks begin with a single quote ' and show in green. VB ignores them — they're for humans.

'Project: Ch01VBUniversity
'D. Bock
'Today's date
'Illustrates displaying information to read-only textbox controls

Always place remarks before the Public Class statement — identify the project, you, and the date.

3 The Assignment Statement

Object.Property = Value

The value on the right of = is assigned to the property on the left.

NameTextBox.Text = "Douglas Bock"
MajorTextBox.Text = "Computer Management & Information Systems"

Text values must be inside double quotes: "Douglas Bock".

5 The Input-Process-Output Model

Every computing program follows this three-step pattern.

INPUT — parse textbox values into memory variables

Dim PriceDecimal As Decimal = Decimal.Parse( _
    PriceTextBox.Text, Globalization.NumberStyles.Currency)

Dim QuantityInteger As Integer = Integer.Parse( _
    QuantityTextBox.Text, Globalization.NumberStyles.Number)

Globalization.NumberStyles.Currency allows a "$" and commas. Without it, "$1,234.56" won't parse.

PROCESS — compute output values

SubtotalDecimal = PriceDecimal * QuantityInteger
SalesTaxDecimal = Decimal.Round( _
    Convert.ToDecimal(SubtotalDecimal * SALES_TAX_RATE_SINGLE), 2)
TotalDueDecimal = SubtotalDecimal + SalesTaxDecimal

OUTPUT — format and display

SubtotalTextBox.Text = SubtotalDecimal.ToString("C")
SalesTaxTextBox.Text = SalesTaxDecimal.ToString("N")
TotalDueTextBox.Text = TotalDueDecimal.ToString("C")

3 If Patterns

Single condition (no Else)

If MedicalCheckBox.Checked Then
    BenefitsCostDecimal += MEDICAL_RATE_DECIMAL
End If

If-Else (both branches)

If HoursDecimal <= 40D Then
    GrossPayDecimal = Decimal.Round(HoursDecimal * PayRateDecimal, 2)
Else
    GrossPayDecimal = Decimal.Round( _
        (40D * PayRateDecimal) + _
        ((HoursDecimal - 40D) * PayRateDecimal * 1.5D), 2)
End If

If-ElseIf-Else (multiple branches)

If GrossPayDecimal <= TAX_LEVEL_08_DECIMAL Then
    FederalTaxDecimal = Decimal.Round(TAX_RATE_08_DECIMAL * GrossPayDecimal, 2)
ElseIf GrossPayDecimal <= TAX_LEVEL_18_DECIMAL Then
    FederalTaxDecimal = Decimal.Round(TAX_RATE_18_DECIMAL * GrossPayDecimal, 2)
Else
    FederalTaxDecimal = Decimal.Round(TAX_RATE_28_DECIMAL * GrossPayDecimal, 2)
End If

4 Logical Operators (MEMORIZE)

OperatorResult is True when...

NotReverses (True→False, False→True)

5 AndAlso / OrElse — Why They Matter

' DANGEROUS — if the value isn't numeric, the second
' comparison crashes.
If IsNumeric(HoursTextBox.Text) And _
   Decimal.Parse(HoursTextBox.Text) <= 60D Then

' SAFE — if the first test fails, VB skips the second
If IsNumeric(HoursTextBox.Text) AndAlso _
   Decimal.Parse(HoursTextBox.Text) <= 60D Then
Critical exam trap Always test for numeric BEFORE testing value ranges. Order matters.

6 Comparing Strings

  • Strings compare character-by-character using ASCII codes
  • Uppercase letters (A-Z, ASCII 65-90) come BEFORE lowercase (a-z, 97-122)
  • Numbers in strings come before letters
  • Space is less than everything
' "Donnie" vs "Doug": "Don" comes before "Dou", so "Donnie" is smaller
' even though it has more characters

' Use ToUpper to compare fairly
If Name1String.ToUpper = "DOUG" Then
    ' ...
End If

7 Select Case

Select Case GrossPayDecimal
    Case Is <= TAX_LEVEL_08_DECIMAL
        FederalTaxDecimal = Decimal.Round(TAX_RATE_08_DECIMAL * GrossPayDecimal, 2)
    Case Is <= TAX_LEVEL_18_DECIMAL
        FederalTaxDecimal = Decimal.Round(TAX_RATE_18_DECIMAL * GrossPayDecimal, 2)
    Case Else
        FederalTaxDecimal = Decimal.Round(TAX_RATE_28_DECIMAL * GrossPayDecimal, 2)
End Select

Select Case rules

  • Use keyword Is before comparison operators: Case Is <= 985D
  • Use keyword To for ranges: Case 25 To 72
  • Combine values with commas: Case 15, 17, 25 To 72, 79, Is > 150
  • Case Else is optional

9 The Full Data Validation Block

Try
    If NameTextBox.Text.Trim = String.Empty Then
        ' Business rule #1: name required
        MessageBox.Show("Name is required", "Name Missing Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
        NameTextBox.Focus()
        NameTextBox.SelectAll()

    ElseIf EmployeeIDMaskedTextBox.Text.Trim.Length <> 11 OrElse _
           EmployeeIDMaskedTextBox.Text.IndexOf(" ", 0, _
               EmployeeIDMaskedTextBox.Text.Length) <> -1 Then
        ' Business rule #2: employee ID incomplete
        MessageBox.Show("Employee ID is not complete", "Employee ID Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
        EmployeeIDMaskedTextBox.Focus()
        EmployeeIDMaskedTextBox.SelectAll()

    ElseIf DepartmentTextBox.Text.Trim = String.Empty Then
        ' Business rule #3: department required
        MessageBox.Show("Department is required", "Department Missing Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
        DepartmentTextBox.Focus()
        DepartmentTextBox.SelectAll()

    ElseIf IsNumeric(HoursTextBox.Text) = False OrElse _
           (Decimal.Parse(HoursTextBox.Text, Globalization.NumberStyles.Number) <= 0D Or _
            Decimal.Parse(HoursTextBox.Text, Globalization.NumberStyles.Number) > 60D) Then
        ' Business rule #4: hours numeric and 0-60
        MessageBox.Show("Hours worked must be a number between 0 and 60", _
                       "Hours Value Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
        HoursTextBox.Focus()
        HoursTextBox.SelectAll()

    ElseIf IsNumeric(PayRateTextBox.Text) = False OrElse _
           Decimal.Parse(PayRateTextBox.Text, _
               Globalization.NumberStyles.Currency) <= 0D Then

                       "Pay Rate Value Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
        PayRateTextBox.Focus()

    Else
        ' ALL valid — process the data (IPO model)
        HoursDecimal = Decimal.Parse(HoursTextBox.Text, _
                                     Globalization.NumberStyles.Number)
        PayRateDecimal = Decimal.Parse(PayRateTextBox.Text, _
                                       Globalization.NumberStyles.Currency)
        ' ... rest of processing
    End If

Catch ex As Exception
    MessageBox.Show("Unexpected error: " & ControlChars.NewLine & ex.Message, _
                   "Compute Button Error", _
                   MessageBoxButtons.OK, MessageBoxIcon.Error)
End Try

11 The Full Payroll Compute Logic (Solution)

Public Class Payroll

    ' Module-level constants

    Private Sub ComputeButton_Click(ByVal sender As System.Object, _
                                   ByVal e As System.EventArgs) _
                                   Handles ComputeButton.Click
        Try
            ' Declare variables
            Dim HoursDecimal, PayRateDecimal As Decimal
            Dim GrossPayDecimal, FederalTaxDecimal As Decimal
            Dim BenefitsCostDecimal, NetPayDecimal As Decimal

            ' Tax constants
            Const TAX_RATE_08_DECIMAL As Decimal = 0.08D
            Const TAX_RATE_18_DECIMAL As Decimal = 0.18D
            Const TAX_RATE_28_DECIMAL As Decimal = 0.28D
            Const TAX_LEVEL_08_DECIMAL As Decimal = 985D
            Const TAX_LEVEL_18_DECIMAL As Decimal = 2450D

            ' Benefit constants
            Const MEDICAL_RATE_DECIMAL As Decimal = 35.75D
            Const LIFE_RATE_DECIMAL As Decimal = 18.35D

            ' --- Data Validation ---
            If NameTextBox.Text.Trim = String.Empty Then

                                "Hours Value Error", _

                HoursTextBox.Focus()

                    Case Is <= TAX_LEVEL_08_DECIMAL

                            TAX_RATE_18_DECIMAL * GrossPayDecimal, 2)
                    Case Else
                        FederalTaxDecimal = Decimal.Round( _
                            TAX_RATE_28_DECIMAL * GrossPayDecimal, 2)
                End Select

                ' Insurance Benefits
                If MedicalCheckBox.Checked Then
                    BenefitsCostDecimal += MEDICAL_RATE_DECIMAL
                End If
                If LifeCheckBox.Checked Then
                    BenefitsCostDecimal += LIFE_RATE_DECIMAL
                End If
                If DentalCheckBox.Checked Then
                    BenefitsCostDecimal += DENTAL_RATE_DECIMAL
                End If

                ' Retirement Benefits
                BenefitsCostDecimal += Decimal.Round( _
                    GrossPayDecimal * RetirementRateDecimal, 2)

                ' Net Pay
                NetPayDecimal = GrossPayDecimal - FederalTaxDecimal - BenefitsCostDecimal

                ' --- Output ---
                GrossPayTextBox.Text = GrossPayDecimal.ToString("C")
                FederalTaxTextBox.Text = FederalTaxDecimal.ToString("N")
                BenefitsTextBox.Text = BenefitsCostDecimal.ToString("N")
                NetPayTextBox.Text = NetPayDecimal.ToString("C")

                ' Enable/disable buttons
                ComputeButton.Enabled = False
                ResetButton.Enabled = True
            End If
        Catch ex As Exception
            MessageBox.Show("Unexpected error: " & ex.Message, _
                            "Compute Button Error", _
                            MessageBoxButtons.OK, MessageBoxIcon.Error)
        End Try
    End Sub

1 What Is an Array

  • A list of values referenced by the same name
  • Like a ListBox without the box
  • Each item is an element
  • Elements numbered starting at 0
  • The number inside parentheses is the subscript or index
  • Based on the System.Array object
' Syntax
ArrayName(ElementNumber)

' Examples
AmountDecimal(3)      ' 4th element of AmountDecimal
StatesString(6)       ' 7th element of StatesString
StatesString(RowInteger)  ' element at index RowInteger

2 Declaring Arrays

' General formats
Dim ArrayName(UpperSubscript) As DataType
Dim ArrayName() As DataType = {ListOfValues}
Dim ArrayName As DataType = {ListOfValues}

' Examples
Dim NameString(25) As String                 ' 26 elements (0-25)
Private BalanceDecimal(10) As Decimal        ' module-level; 11 elements

' With immediate values (do NOT specify size)

                                    "Business", "Nursing", _
                                    "Engineering", "Education", "Pharmacy"}

Numeric arrays default to 0; string arrays default to empty string.

3 Subscript Errors

' If array has 10 elements (0-9) and you access index 10 or -1:
' Runtime exception: System.IndexOutOfRangeException

Always keep subscripts between 0 and UpperSubscript.

4 Processing Arrays with Loops

For...Next

For RowInteger = 0 To NumberOfSchoolsInteger

Next RowInteger

For Each...Next (no index counter needed)

Rules for For Each...Next

  • Index variable's data type must match the array's data type
  • Cannot modify array values (read-only iteration)
  • Cannot iterate backwards or use Step

Reinitialize numeric arrays

For Each IndividualElementInteger As Integer In TotalInteger

Next IndividualElementInteger

13 The Delete Procedure

Private Sub BindingNavigatorDeleteItem_Click(ByVal sender As System.Object, _
                                        ByVal e As System.EventArgs) _
                                        Handles BindingNavigatorDeleteItem.Click
    Dim RowNumberInteger As Integer = StudentBindingSource.Position
    Try
        Dim ResponseDialogResult As DialogResult = MessageBox.Show( _
            "Confirm to delete the student record.", "Delete Y/N?", _
            MessageBoxButtons.YesNo, MessageBoxIcon.Question, _
            MessageBoxDefaultButton.Button2)
        If ResponseDialogResult = Windows.Forms.DialogResult.Yes Then
            StudentBindingSource.RemoveCurrent()
            StudentBindingSource.EndEdit()
            TableAdapterManager.UpdateAll(StudentDetailsDataSet)
        End If
    Catch exOleDb As OleDb.OleDbException
        ' Foreign key violation — student is enrolled in courses
        StudentDetailsDataSet.RejectChanges()
        StudentBindingSource.Position = RowNumberInteger
        MessageBox.Show("This student cannot be deleted - the student is " & _
                        "enrolled in courses." & ControlChars.NewLine & _
                        exOleDb.Message, "Delete Operation Error", _
                        MessageBoxButtons.OK, MessageBoxIcon.Error)
    Catch ex As Exception
        MessageBox.Show("Unexpected error: " & ex.Message, _
                       "Delete Operation Error", _
                       MessageBoxButtons.OK, MessageBoxIcon.Error)
    End Try
End Sub

Important: the student's DataSet column is restored via RejectChanges if the delete fails.

14 RowState Concept (Critical)

Each DataRow tracks its state:

RowStateMeaning
AddedNew row not yet saved to database
ModifiedExisting row whose columns changed
DeletedRow marked for deletion
UnchangedRow matches database

UpdateAll reads RowState for each row and decides INSERT, UPDATE, or DELETE.

16 Access Database Fix for 64-bit Windows

The Microsoft.Jet.OLEDB.4.0 provider is only available in 32-bit. On 64-bit Windows, you get:

The 'Microsoft.Jet.OLEDB.4.0' provider is not registered on the local machine.

Fix (full Visual Studio):

  1. Solution Explorer → double-click My Project
  2. Click the Compile tab
  3. Click Advanced Compile Options...
  4. Set Target CPU to x86

Fix (VB Express Edition): edit the .vbproj file manually — add <PlatformTarget>x86</PlatformTarget> inside the first <PropertyGroup> section.

17 Copy to Output Directory

By default, the database file is copied to \bin\Debug on every run, so saves are lost. Fix:

  • Select the .mdb/.mdf file in Solution Explorer
  • Properties → Copy to Output Directory = Copy if newer

Exam Prep

Top 20 Things You Must Remember

Your highest-probability exam traps, in one place. Read this the night before.

1-5 Foundations

  • RadioButtons use CheckedChanged, not Click. Same for CheckBoxes.
  • AndAlso / OrElse prevent crashes — always test IsNumeric before Decimal.Parse.
  • Input-Process-Output — every computing program follows this three-step pattern.
  • Option Strict On — placed after comments, before Public Class. Forces explicit conversion.
  • Data type suffixes: D = Decimal, F = Single, I = Integer, L = Long, S = Short, R = Double.

6-10 Calculations & Validation

  • Globalization.NumberStyles.Currency — needed to parse "$1,234.56".
  • Decimal.Round(expression, 2) — always round money calculations.
  • Format codes: "C" = currency, "N" = number, "N0" = no decimals.
  • Order of precedence: () → ^ → * / → \ → Mod → + -.
  • Validation order matters: test missing data, then numeric, then range.

11-15 Logic & Loops

  • Handles clause — one procedure can handle multiple controls' events.
  • ByVal vs ByRef — ByVal sends a copy (safe), ByRef sends memory (can change original).
  • For Each...Next — processes entire array without counter.
  • Do...Loop While (test at bottom) — always runs at least once.
  • Exit For / Exit Do — leave a loop early.

16-20 Arrays & Database

  • Arrays start at index 0. Invalid index throws IndexOutOfRangeException.
  • 2D array: Array(row, column) — row FIRST.
  • Structure = custom data type with multiple fields.
  • Connection chain: Data Source → BindingSource → TableAdapter → DataSet → Controls.
  • RowState: Added, Modified, Deleted, Unchanged. UpdateAll reads this to decide INSERT/UPDATE/DELETE.
If you can do these four things, you'll pass 1. Write a payroll calculator with If/ElseIf for tax brackets.
2. Build a form with validation (missing data, numeric, range).
3. Use a For...Next loop to sum or count.
4. Write a search procedure that scans an array and displays the found record.
